## Finding baru dan perbaikan

### IDN-FUNC-002 — Pesan wajib foto sesudah tidak tampil pada form admin

- **Severity:** Medium.
- **Akar masalah:** `ReportStatusService` melempar pesan validasi dengan key `after_photo`, sementara properti dan Blade Livewire menggunakan `afterPhoto`.
- **Reproduksi:** Sarpras membuka laporan fasilitas berstatus `diproses`, memilih `Selesai` tanpa foto, lalu menyimpan.
- **Sebelum perbaikan:** server menolak perubahan sesuai aturan, tetapi error tidak terhubung ke elemen upload sehingga pengguna tidak memperoleh pesan spesifik di sana.
- **Perbaikan:** error key diselaraskan menjadi `afterPhoto`.
- **Regression test:** `tests/Feature/AdminReportHandlingTest.php`, memastikan component memiliki error pada `afterPhoto`, menampilkan teks panduan, dan tidak mengubah status/histori/lampiran.
- **Verifikasi:** tes fokus PASS (1 test, 7 assertions); browser E2E setelah foto wajib PASS.
